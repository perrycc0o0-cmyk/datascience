# Expression analysis and figures

Run these scripts from the `drugaddiction` directory. Use a separate, empty directory for each output. The analysis scripts write the results and an R session report; the plotting scripts consume those results without refitting or adjusting the statistics.

## Inputs and environment

- Use the `01_inputs/Excitatory/IEGhigh_payload.rds` and `01_inputs/Inhibitory/IEGhigh_payload.rds` files generated by the upstream analysis. Each payload contains a sparse genes-by-nuclei integer count matrix (`counts`), aligned nucleus metadata (`metadata`), and aligned feature annotations (`gene_annotation`). Pool IDs are `WD1`–`WD3`, `Ext1`–`Ext3`, and `Ret-Ext1`–`Ret-Ext3`.
- The recorded expression environment used R 4.5.1, DESeq2 1.50.2, edgeR 4.8.2, Matrix 1.7.4, Monocle 2 (`monocle` 2.38.0), DDRTree 0.1.5, igraph 2.2.1, dplyr 1.1.4, and fgsea 1.36.2. The trajectory script checks its version-sensitive dependencies. The network builder uses only the Python 3 standard library.
- Plotting requires Arial Regular and Bold, R with Cairo, `ragg`, `svglite`, and `systemfonts`. Volcano and trajectory plots use `ggplot2`; volcano labels additionally use `ggrepel`. The recorded rendering environment used `ggplot2` 4.0.3, `ggrepel` 0.9.8, `ragg` 1.5.2, `svglite` 2.2.2, and `systemfonts` 1.3.2.

## Pseudobulk differential expression and volcano plots

```sh
Rscript expression/pseudobulk_deseq2.R work/stage3/01_inputs/Excitatory/IEGhigh_payload.rds work/stage3/01_inputs/Inhibitory/IEGhigh_payload.rds work/deseq2
Rscript expression/plot_deseq2_volcanoes.R work/deseq2 work/volcanoes
```

Sum counts within each independent pool and neuronal class. Fit `~ condition` for each two-condition comparison, using the three independent pools in each condition. The initial expression filter is recomputed within each contrast using `edgeR::filterByExpr`. The DESeq2 Wald analysis uses median-of-ratios normalization, native Cook's-distance protection, default independent filtering at `alpha = 0.05`, and BH adjustment. The WD contrasts retain the same-model convergence retry at `maxit = 1000` only if needed.

`datasets/<class>__<contrast>/tables/ALL_genes.csv` retains the original feature universe, including the rows not fitted or not assigned an adjusted P. `BH005_genes.csv` contains all native BH results below 0.05. The volcanoes plot native adjusted P values and apply `abs(log2FoldChange) >= log2(1.15)` only for identifying/labeling displayed hits; it is not a separate DE test.

## Signature-guided trajectories

```sh
Rscript expression/signature_trajectories.R work/stage3/01_inputs/Excitatory/IEGhigh_payload.rds work/deseq2/datasets/Excitatory__RetExt_vs_Ext/tables/ALL_genes.csv work/trajectories
Rscript expression/plot_signature_trajectories.R work/trajectories work/trajectory_figures
```

Keep the six-pool excitatory Ret-Ext vs Ext eligibility mask but fit `~ condition` with all nine pools to estimate the ranking contrast. Rank genes separately by fold-change direction, ascending nominal P, descending absolute log2 fold change, then feature identifier. Fit one independent Monocle 2 DDRTree trajectory for each direction and each signature size (10, 20, 30, 40, 50, 100, 200, 300, 400, 500). The manuscript display uses the two 40-gene signatures.

Set the trajectory root to the structurally eligible state containing the most WD nuclei, breaking ties by smaller numeric state. Compare the three Ext and three Ret-Ext pool means with a two-sided Welch test. BH adjustment uses the full 20 planned cases, retaining unavailable results for failed fits. Pseudotime is a relative transcriptional coordinate, not elapsed time. Signatures and group comparisons use overlapping samples; this analysis is not an independent validation of the DE signature.

## Candidate GSEA and gene-category network

```sh
Rscript expression/candidate_gsea.R work/deseq2 references/excitatory_symbol_entrez.csv references/inhibitory_symbol_entrez.csv references/rat_candidate_pathway_membership.csv work/gsea
Rscript expression/plot_candidate_gsea.R work/gsea work/gsea_figures
python expression/gene_category_network.py work/deseq2 work/gsea work/gene_category_network
Rscript expression/plot_gene_category_network.R work/gene_category_network work/network_figures
```

The repository includes the 43 pathway IDs, display names, and original candidate order. The reference annotation itself is external:

- Supply the matching frozen per-class rat `SYMBOL,ENTREZID` mapping snapshots. For exact reproduction, use the complete mapping records (including same-snapshot augmentation) from the original analysis. The source mapping used `org.Rn.eg.db` 3.22.0 and `AnnotationDbi` 1.72.0.
- Supply the matching frozen pathway membership as `ID,Entrez`, one row per pathway–Entrez pair, from authorized GO, KEGG and Reactome reference files. For exact reproduction, include the recorded rat Reactome membership for `R-RNO-399719` and retain original ordering within each pathway. The release does not contain the reference membership snapshot; current online databases can give different results.

GSEA uses all genes with finite native signed Wald statistics and nominal P values, not only DE hits. It removes ambiguous symbol mappings and retains the largest-baseMean representative for repeated Entrez IDs, breaking ties by feature identifier. It uses weighted `fgseaMultilevel` with seed 42, set sizes 10–1000, `eps = 0`, 101 multilevel samples, and 1,000 simple permutations. Each class receives a separate BH adjustment across its finite candidate tests. The ridge plot displays all nominal `P < 0.05` pathways; fill indicates `-log10(FDR)`, point color indicates NES, and point area indicates `abs(NES)`. The density uses actual leading-edge gene log2 fold changes.

The network groups the 14 selected excitatory pathways into six named categories. A link is a gene-to-category membership, not a protein–protein interaction. It connects genes with nominal DE `P < 0.05` to categories using full pathway membership; it does not restrict genes to the leading edge. The isolated two-gene upregulated component is excluded only from the approved display and remains in `network_nodes.csv` and `network_edges.csv`.

The network renderer can recalculate the fixed-seed, anchored layout. Label placement depends on font metrics and graphics software. To use the exact approved coordinates, append the archived downregulated and upregulated `*_nodes_and_layout.csv` files as the third and fourth arguments, respectively. These coordinates are external; the renderer checks their nodes and values against the current display tables before drawing. Combined output has no panel tags and no text backgrounds.
